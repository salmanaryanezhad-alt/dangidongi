# دنگی‌دنگی

اپ وب سبک برای مدیریت خرج مشترک خونه (۳ تا ۶ نفر)، جایگزین اکسل مشترک.
هر عضو هر خرید رو ثبت می‌کنه، بقیه بلافاصله از طریق SSE می‌بینن، و آخر ماه اپ می‌گه کی به کی چقدر بده.

## منطق اصلی

- هر هزینه یک پرداخت‌کننده داره و بین اعضا با **ضریب سهم** تقسیم می‌شه:
  `0` = سهیم نیست، `1` = سهم کامل، `2` و بیشتر = سهم بیشتر (مثلاً مهمون داره)
- سهم هر عضو = `(مبلغ ÷ مجموع ضریب‌ها) × ضریب اون عضو` — با **floor**
- باقی‌مانده‌ی تقسیم به نفر اول اضافه می‌شه تا جمع دقیقاً برابر مبلغ بشه
- تراز هر عضو = مجموع پرداختی‌ها − مجموع سهمش (تراز کل همیشه صفره)
- تسویه پیشنهادی: بزرگ‌ترین بدهکار به بزرگ‌ترین طلبکار، به اندازه‌ی `min(|بدهی|، طلب)`
- مبلغ‌ها عدد صحیح تومان (BIGINT) — بدون اعشار

## نصب روی هاست اشتراکی

1. دیتابیس و جدول‌ها را بسازید (فایل `schema.sql` را در phpMyAdmin یا با
   `mysql -u USER -p < schema.sql` اجرا کنید).
2. مشخصات اتصال دیتابیس را در `includes/db.php` وارد کنید
   (`DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASS`).
3. همه‌ی فایل‌ها را در روت هاست آپلود کنید. تمام — صفحه‌ی `index.php` اپ است.

> نکته برای هاست اشتراکی: استریم SSE هر اتصال را پس از ~۵۰ ثانیه می‌بندد و مرورگر
> خودش دوباره وصل می‌شود (با `Last-Event-ID`، پس رویدادی گم نمی‌شود). این محدودیت
> عمداً گذاشته شده تا فشار روی هاست اشتراکی کم بماند.

## اجرای محلی برای تست

```bash
# ۱) ساخت دیتابیس
mysql -u root -p < schema.sql

# ۲) تنظیم includes/db.php و اجرا
PHP_CLI_SERVER_WORKERS=8 php -S localhost:8080
```

`PHP_CLI_SERVER_WORKERS` لازم است تا اتصال‌های بازِ SSE جلوی بقیه‌ی درخواست‌ها را نگیرند.

## ساختار فایل‌ها

```
/
├── index.php          → صفحه اصلی (۴ نما: ورود/ساخت خونه، اصلی، ثبت هزینه، گزارش)
├── schema.sql         → ساخت دیتابیس و ۵ جدول
├── api/
│   ├── auth.php       → ساخت خونه / ورود با کد دعوت (POST)
│   ├── expenses.php   → لیست (GET) و ثبت (POST) هزینه
│   ├── balances.php   → تراز اعضا + تسویه پیشنهادی (GET)
│   ├── members.php    → لیست اعضا (GET)
│   └── stream.php     → Server-Sent Events
├── includes/
│   ├── db.php         → اتصال PDO + خروجی JSON + ثبت رویداد
│   ├── calc.php       → تقسیم سهم، تراز، تسویه پیشنهادی
│   └── auth_check.php → چک توکن عضو
└── assets/
    ├── app.js         → منطق فرانت‌اند (بدون هیچ کتابخانه‌ای)
    └── style.css      → استایل فارسی، RTL، موبایل‌فرست
```

## جدول‌های دیتابیس

| جدول | نقش |
|---|---|
| `houses` | هر خونه با اسم و کد دعوت |
| `members` | اعضای هر خونه با یک توکن ساده |
| `expenses` | هر هزینه (نام، مبلغ، پرداخت‌کننده) |
| `expense_shares` | ضریب و سهم نهایی هر عضو از هر هزینه |
| `events` | هر تغییر اینجا ثبت می‌شه، برای SSE |

## رابط کاربری

فارسی و RTL کامل، موبایل‌فرست، تقویم شمسی (با `Intl` مرورگر)، واحد تومان با
جداکننده‌ی هزارگان، سبز = طلبکار و قرمز = بدهکار.

## خارج از دامنه در نسخه اول

پرداخت درون‌اپ، احراز هویت پیچیده، فریم‌ورک جاوااسکریپت، WebSocket، اعلان push، آپلود رسید.

## نسخه‌ی آفلاین و اپ اندروید

- `offline/index.html` — نسخه‌ی تک‌فایل آفلاین (داده در localStorage مرورگر). همین فایل
  به‌تنهایی روی گوشی هم باز می‌شود و به‌صورت PWA نصب‌پذیر است.
- `android/` — پروژه‌ی کامل Android Studio: همین اپ را داخل WebView اجرا می‌کند،
  بدون هیچ دسترسی‌ای (کاملاً آفلاین). بازش کنید و Run بزنید تا APK ساخته شود.
  پشتیبان‌گیری از طریق بریج جاوا روی دستگاه ذخیره می‌شود.

## نسخه‌ی آنلاین برای ورسل — Next.js (پوشه‌ی `vercel/`)

ورسل PHP اجرا نمی‌کند، بنابراین این نسخه با **Next.js** پیاده‌سازی شده:
UI با React، بک‌اند با API Routes (pages/api)، دیتابیس **Vercel KV**
(Upstash، لایه‌ی رایگان) و همگام‌سازی با polling هر ۳ ثانیه
(ورسل اتصال باز SSE نمی‌پذیرد). منطق تقسیم/تراز/تسویه در `lib/calc.js`
بین کلاینت و سرور مشترک است.

### دیپلوی

1. در ورسل: **Add New Project → Import** این مخزن؛ **Branch** را روی شاخه‌ی کاری بگذارید
   (یا PR را مرج کنید تا روی main بیاید) و **Root Directory** را `vercel` بگذارید.
   فریم‌ورک به‌صورت خودکار Next.js تشخیص داده می‌شود.
2. در داشبورد پروژه: **Storage → Create → KV** و آن را به پروژه وصل کنید
   (متغیرهای `KV_REST_API_URL` و `KV_REST_API_TOKEN` خودکار ست می‌شوند).
3. **Redeploy** کنید. تمام — آدرس پروژه را باز کنید و با کد دعوت، چند گوشی را وصل کنید.

### تست محلی

```bash
cd vercel
npm install
KV_MEMORY=1 npm run dev    # با KV حافظه‌ای، بدون نیاز به هیچ سرویسی
```
